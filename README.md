# IT Security Shell Automation

## Overview

This project was developed as part of my studies in IT Security Development at EC Utbildning.

The purpose of the project is to explore how Bash, PowerShell and Python can be used to automate basic security checks, collect system information and analyse potential security risks across Linux and Windows environments.

The project combines scripting, security analysis and automation into a simple cross-platform security workflow.

---

## Features

### Linux / Bash
- Collects system and security-related information
- Analyses running processes
- Identifies potentially risky processes and tools
- Generates structured output for further analysis

### Windows / PowerShell
- Checks Windows services
- Identifies administrator accounts
- Checks failed login attempts
- Collects security-related system information

### Python
- Processes collected security data
- Performs basic risk analysis
- Works with JSON and CSV data
- Generates a security report based on the collected information

## How It Works

The project follows a basic security automation workflow:

1. Bash or PowerShell scripts collect information from the operating system.
2. The scripts perform different security-related checks.
3. Results are stored as structured data.
4. Python is used to analyse the collected information.
5. Potential security risks are identified and presented in a security report.
